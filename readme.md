# 麦克纳姆轮小车运动控制系统

> 🎮 **本分支新增**：游戏手柄操控 · 控制延迟降低 75% · 速度/转向曲线优化 · 详细改动见末尾章节。

## 项目概述

本项目为"汽车数字设计"课程设计——基于 STM32F103RCT6 的麦克纳姆轮小车运动控制系统，集成 K230 AI 视觉模块与 PC 上位机，形成**三端协同**的智能机器人平台。

| 层级 | 硬件 | 功能 |
|------|------|------|
| 上位机 | PC (PyQt5) | 远程遥控、摇杆操控、手柄支持、图传显示 |
| 视觉层 | K230 (Micropython) | AI 视觉、WiFi 图传、UDP→UART 指令转发 |
| 控制层 | STM32F103RCT6 | 运动解算、PID 速度环、编码器读取、OLED 交互 |

```
┌──────────────────┐     WiFi / TCP      ┌──────────────────┐
│   PC 上位机       │ ◄──────────────────► │   K230 视觉模块    │
│  (PyQt5 + 手柄)   │   图传 + UDP 指令   │  (摄像头 + 转发)   │
└────────┬─────────┘                     └────────┬─────────┘
         │ 游戏手柄 (XInput)                       │ UART
         └─────────────────────────────────────────┤
                                          ┌────────┴─────────┐
                                          │  STM32F103RCT6    │
                                          │  (运动控制器)      │
                                          └────────┬─────────┘
                                                   │ PWM + 编码器
                                          ┌────────┴─────────┐
                                          │  四路电机 + 编码器 │
                                          └──────────────────┘
```

### STM32 控制流程

```
TIM1 中断 (20ms)
  ├── motor_speed_update()     # 读取编码器，计算四路 RPM
  └── Motion_Control(Vx,Vy,w)  # 运动学解算 → PID → PWM 输出
       └── if target==0: 直接刹车，清零 PID 状态

主循环 (50ms)
  └── OLED 显示当前 Vx/Vy/w 及 UART 帧计数

UART 通信
  └── USART3 (PB10/PB11): 接收 K230 转发的速度指令
       帧格式: 0x55 0x54 + Vx(int16) + Vy(int16) + w(int16×1000) + XOR校验
```

### K230 视觉系统

`k230_video_stream.py` — 三合一：WiFi 图传服务端 + UDP 指令接收 + UART 转发到 STM32。

- 双通道摄像头：Ch0 YUV→LCD 硬件直连，Ch1 RGB→JPEG→TCP 无线图传
- UDP 端口 8889 接收上位机速度指令 `"Vx,Vy,w\n"`
- UART2 转发到 STM32，自定义 9 字节帧 + XOR 校验

### PC 上位机

`robot_control_upper.py` — 基于 PyQt5 的深色科技风遥控界面：

- **视频预览区**：K230 图传实时画面（TCP:8888）
- **速度指令面板**：Vx/Vy 方向矢量图 + w 指示条 + 数值实时显示
- **双摇杆**：方向摇杆 + 旋转摇杆，支持鼠标拖拽
- **🎮 游戏手柄**：XInput 即插即用（详见下方）
- **急停按钮**：一键紧急停止
- **10ms 控制周期**：每秒 100 次指令发送

## 电机参数

| 参数 | 值 |
|------|-----|
| 编码器脉冲/转 | 780（含 2 倍频） |
| PWM 频率 | 1kHz（TIM3, PSC=71, ARR=999） |
| 控制周期 | 20ms（TIM1, PSC=7199, ARR=200） |
| PID 参数 | Kp=3.0, Ki=2.0, Kd=0 |
| 积分限幅 | ±200 |
| 输出限幅 | ±1000 |

### PID 零目标优化

当目标转速为 0 时，跳过 PID 运算，直接输出 PWM=0 并清零积分/微分状态，确保快速刹停。

## 构建方法

### STM32 固件

- **工具链**: GCC ARM None EABI (`arm-none-eabi-gcc`)
- **构建系统**: CMake 3.22+ + Ninja

```bash
cd stm32f103rct6
cmake --preset Debug
cmake --build build/Debug
```

当前固件大小：Flash ~29KB / 256KB, RAM ~3.8KB / 48KB。

### K230 部署

将 `k230/k230_video_stream.py` 重命名为 `main.py` 放入 MicroSD 卡根目录，上电自动运行。

### PC 上位机

```bash
cd Host_computer
pip install pyqt5 pillow        # 无需 opencv-python
python robot_control_upper.py
```

## 操控方式

| 手柄 | 屏幕/键盘 | 功能 |
|------|-----------|------|
| 左摇杆 | 屏幕左摇杆 / WASD | 方向控制 |
| 右摇杆 X | 屏幕右摇杆 / AD | 旋转 |
| RT 右扳机（按住） | — | 满油门 400 mm/s，忽略速度上限 |
| LT 左扳机 | 空格 / STOP 按钮 | 刹车 |
| RB | E 键 | 速度上限 +50（0→50→...→400） |
| LB | Q 键 | 速度上限 -50 |

- 🎮 手柄即插即用，手柄与键鼠**可同时操控**，各自独立判断
- 手柄摇杆归中后自动切回键盘/屏幕摇杆
- 摇杆深度² × 速度上限 = 实际速度（轻推慢走、重推快走）

## 参数配置

| 参数 | 原值 | 本分支值 |
|------|------|----------|
| 最大速度上限 | 600 mm/s | **400 mm/s** |
| 速度起步值 | — | **0**（按 RB/E 解锁，50/档） |
| 最大角速度 | 5.0 rad/s | **2.0 rad/s** |
| 上位机控制周期 | 100ms | **10ms（PreciseTimer）** |
| 左摇杆速度曲线 | 线性 | **二次**（摇杆深度² × 上限） |
| 右摇杆转向曲线（手柄） | 线性 | **三次**（行程短，更细腻） |
| 右摇杆转向曲线（屏幕） | 线性 | **二次** |
| 手柄支持 | 无 | **XInput 原生** |
| LT 左扳机 | — | 按住刹车 |
| RT 右扳机 | — | 按住满油门 400 |

## 控制延迟

| 环节 | 原值 | 优化后 |
|------|------|--------|
| 上位机定时器 | 100ms | 10ms PreciseTimer |
| K230 UDP 检查 | 1次/循环 | 3 点覆盖（循环头+抓帧后+循环尾），排空缓冲 |
| K230 TCP 发送 | 单次阻塞 | 单次 send |
| K230 JPEG 画质 | 15 | 15（不变） |
| **平均延迟** | **~130ms** | **~25ms** |
