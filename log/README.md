# 项目工作日志

## 项目概述

本项目为"汽车数字设计"课程设计——基于 STM32F103RCT6 的麦克纳姆轮小车运动控制系统。

- **MCU**: STM32F103RCT6 (72 MHz, HSE 8MHz × PLL 9)
- **工具链**: GCC ARM None EABI + CMake + Ninja
- **代码生成**: STM32CubeMX（硬件初始化代码）

---

## 已完成工作

### 2026-05-28 — 项目初始化与基础框架搭建

| 模块 | 完成内容 |
|------|----------|
| **HAL 层配置** | 系统时钟（72MHz）、GPIO、TIM1/2/3/4/8、I2C1、USART1 全部通过 CubeMX 生成并配置完毕 |
| **电机驱动 (Motor)** | 四路直流电机驱动：PWM 输出（TIM3，1kHz）、方向控制 GPIO、四路编码器读取（TIM2/TIM4/TIM8 硬件编码器 + 电机D 软件 EXTI 编码器）、每 20ms 速度采样并计算 RPM |
| **PID 控制器 (Motor)** | 四路独立 PID 速度环（Kp=3.0, Ki=2.0, Kd=0），积分限幅 ±200，输出限幅 ±1000，20ms 固定周期 |
| **麦克纳姆轮运动学 (Mecanum)** | X 型布置逆运动学解算，底盘速度 (Vx, Vy, w) → 四轮 RPM，车轮直径 60mm，轴距 120mm，轮距 196mm |
| **OLED 显示 (OLED)** | SSD1306 驱动移植（I2C1，0x78 地址），支持：帧缓冲操作、点/线/矩形/三角形/圆/椭圆绘制、ASCII 及中文字体渲染（4 种英文字体 + 中文框架）、位图渲染 |
| **循迹传感器** | 四路传感器读取（PB12-PB15），下拉输入模式 |
| **主循环** | 每 50ms 刷新 OLED 显示：四路传感器状态、四路编码器增量、电机D RPM |
| **运动控制** | 中断中调用 `Motion_Control()` 实现闭环运动（当前硬编码 Vx=0, Vy=400mm/s, w=0 用于测试） |
| **PCB 扩展板** | Altium Designer 项目已完成，原理图 PDF 已导出 |

### 2026-05-28 — 引脚与中断总览

| 外设 | 引脚 | 功能 |
|------|------|------|
| TIM2 编码器 | PA15(CH1), PB3(CH2) | 电机A 编码器（部分重映射） |
| TIM3 PWM | PA6(CH1), PA7(CH2), PB0(CH3), PB1(CH4) | 四路电机 PWM 输出 |
| TIM4 编码器 | PB6(CH1), PB7(CH2) | 电机B 编码器 |
| TIM8 编码器 | PC6(CH1), PC7(CH2) | 电机C 编码器 |
| EXTI | PA1, PA2 | 电机D 软件编码器（上升沿中断） |
| GPIO Out | PA11/PA12, PC10/PC11, PC12/PD2, PC8/PC9 | 四路电机方向控制 |
| GPIO In | PB12-PB15 | 四路循迹传感器 |
| I2C1 | PB8(SCL), PB9(SDA) | OLED 通信（重映射，400kHz） |
| USART1 | PA9(TX), PA10(RX) | 串口通信（115200 8N1，暂未使用） |
